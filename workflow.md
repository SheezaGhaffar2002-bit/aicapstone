# AI Workflow Comparison

## Feature

The feature I selected for this exercise was an **Add Transaction Form** for my Expense Tracker application.

## Round One – Vague Prompt

For the first round, I used a very simple prompt without giving detailed requirements. The AI generated a basic transaction form with the required fields, but it lacked strong validation, accessibility features, and clear error handling. The code was functional but required significant manual review and improvements before it could be used confidently.

## Round Two – Detailed Prompt

For the second round, I started a fresh AI conversation and used a detailed prompt. I specified the required fields, validation rules, accessibility requirements, Tailwind CSS styling, responsive design, and requested that the AI verify the solution after generating the code. The resulting form was much more complete, organized, and easier to understand. It included better validation, improved accessibility, cleaner structure, and required much less manual correction.

## Comparison

The detailed prompt produced noticeably better results than the vague prompt. The second version included proper labels for inputs, accessible error message placeholders, improved Tailwind CSS styling, better code organization, and more comprehensive validation. The code was easier to read because it used a clearer structure and more meaningful naming. The first version focused mainly on generating the form, while the second version addressed usability and quality.

Although writing the detailed prompt took longer, reviewing and fixing the generated code required much less time. Overall, the detailed workflow was more efficient.

## AI Mistake I Caught

One issue I noticed in the first version was that it relied mainly on basic HTML validation and did not provide clear validation feedback or accessible error messages. I identified this during review and ensured these improvements were included in the second version.

## What I Learned

This exercise showed me that the quality of the AI output depends heavily on the quality of the prompt. A detailed prompt with clear requirements, constraints, accessibility expectations, and verification instructions produces better code and reduces the amount of manual review. Going forward, I will use structured prompts and always review AI-generated code before using it in my projects.
