# Project Guidelines
- Stack: Node.js, JavaScript/TypeScript
- Style: Clean code, modular patterns
- Commits: Follow Conventional Commits format
## Project-Specific Rules Learned

1. Every form must validate required fields before allowing submission.

2. Every input must have a visible label and accessible error messages (`aria-live` where appropriate).

3. Use Tailwind CSS utility classes consistently for spacing, colors, and responsiveness.

4. Review and test AI-generated code before committing it to the repository.

5. Build mobile-first layouts and verify responsiveness on different screen sizes.
